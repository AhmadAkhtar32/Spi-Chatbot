### Chart of Accounts Setup 

On the main menu screen go to the setup menu and then select Chart of
Accounts. This will further display three options Maintain, Copy and
Copy chart of Account (company). Each of these is discussed in the
following pages.

The Chart of Accounts setup screen that you are looking at allows you to
enter a variety of information regarding your Chart of Accounts. I will
start from the basics, the **Maintain** menu.

The Chart of Accounts setup screen is partitioned into three core areas
of functionality for your ease of use.

Firstly, a list of account heads entered in the system is displayed in
the left corner of the screen. It contains the code and the title of
account. A search facility is also provided, at the bottom left corner,
which could be invoked using code or title as the primary search
criteria.

Secondly, the usual "system functions area" where you have the function
buttons such as "New," "Edit" etc. are displayed at the bottom of the
screen.

Thirdly, on the right side of your Chart of Accounts setup screen,
details pertaining to the account heads displayed in the list are shown.
These details are briefly discussed below:

### Secondary Chart of Accounts setup 

As the name implies, it is via this option that single or multiple setup
of Chart of Accounts are maintained in the system. Conceptually,
secondary Chart of Accounts relates to the mapping of a group of unique
ledger account heads with a group within the main Chart of Accounts of a
company. For example, a company operating nationwide may have its
consolidated national sales ledger account heads reflecting total sales
at the head office. This consolidated position is to be built up by
merging the sales carried out at it 4 regional offices. The sale of a
particular product at each regional office is to be reflected in a
particular account at the head office. It is here that a secondary Chart
of Accounts may come into use. The user may create 4 Secondary Chart of
Accounts (COA) where each COA reflects a region and each account within
the COA reflects the sale of a particular product. This may now be
mapped with the main sales Account Heads at the head office.
Subsequently, each transaction recorded in the secondary COA will be
reflected in the main COA of the company and consequently shown in
related reports. The option to map these accounts is available in the
main COA setup, while through this option the secondary COA(s) is (are)
defined.

[Getting there:]{.underline}

On the main menu screen go to the setup menu and then select Secondary
Chart of Accounts. This will display a screen containing the following
options/buttons, which are briefly discussed below:

[Adding Information "Function Keys Tab":]{.underline}

This tab page contains an option to define standard function keys for
the voucher type. Text or a number may be entered against a particular
function key and resultantly when the function key is pressed during
voucher entry, the value entered here is displayed at that time. This
may usually be used to save time during data entry via pressing a single
function key to achieve the desired results. For example, if '10000' is
defined against the function key F1 then every time key F1 is pressed
(during the voucher entry) the system will fill the selected field with
the value '10000'. The function key F-2 is by default disabled and it is
used to as a pick list. Similarly, function key F-10 is also disabled.

available in the voucher setup. These buttons are used for the analysis

the "sequential" button for example, authority 1, authority 2 while for
random names, click on the "random" button for example, authority 2,
authority 1.

include, Page Settings, Orientation, Zoom factor, Page size, Picture to
be displayed in background, its size and position, Text printing options
etc. Header, Detail and Footer options are also customized via this
option. The usage is simple and requires the user to check or leave
blank various check boxes in addition to defining fonts etc.

### User Group Setup 

The purpose of user group creation is to facilitate the user in defining
system security. The software you have purchased accommodates security
features at all usage levels, ranging from menu to button level. You can
make certain features available for certain people and the same could be
made unavailable for others.

Do I have to define each and every security feature for every
individual? I know this could become really cumbersome and that's where
our user group features come in handy. You can define different levels
of security for various groups and then later individuals can be simply
put into different user groups. Thus will have all the privileges of
that particular group. Following is how it will work:

[Getting there:]{.underline}

On the main menu screen go to the setup menu and then select user group.
This will display the users group setup screen we will be talking about.

[Adding information to Users Groups:]{.underline}

>  **New:** You can add user groups to
> your system by simply clicking on the "New" button. A screen titled
> "Define New User Group" will appear**.**

Enter the code and the name of the user group and then come down to the
purchase system displayed in the window on the right. In the screen
shown above, you can work at the upper most level. Where you can define
which menus you would want, for example, the data entry group to have
access to. The screen on the right shows the options and the user is
provided with a check box.

Similarly, you can go down to different levels of details while defining
accessibility for a particular user group. Simply by cascading (click
the plus sign next to purchase system) "purchase system" displayed on
the screen, a list of all the menus will be displayed. You can now
follow the same procedure for assigning accessibility.

Finally, you can go down to the button level on a particular screen of a
menu select or unselect the options available as required.

>  **Ok:** Once, you have defined all
> the necessary options for a particular group you can save that by
> pressing the "**Ok**" button. This will create a user group named
> "Data Entry" (shown below).
